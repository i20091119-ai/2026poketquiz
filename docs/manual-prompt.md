# 설명서 만들기 프롬프트 (개발 챗방에 그대로 붙여 넣기)

---

포켓몬 배움 탐험대(저장소 `i20091119-ai/2026poketquiz`, 작업본 `claude/vibrant-bell-ru08mi`)의 **포켓몬 마을 설명서**를 만들어 줘.

## 누가 읽나
- **아이용(초등 1학년):** 아이가 "뭘 누르는지, 뭘 줍는지, 뭘 쓰는지, 재료는 어디서 나오는지" 헷갈려 해. 한 장에 한 가지만, 그림(실제 게임 화면 캡처)과 아주 짧은 문장으로.
- **부모용:** 같은 내용을 한 장짜리 표로. 숫자(하루 몇 번, 몇 개)와 보호자 공간에서 바꾸는 곳까지.

## 지켜 줄 것
- 아이용 문장은 초1 눈높이: 한 문장 15자 안팎, 반말("~해 봐", "~하면 돼"), 어려운 낱말 금지. "스탯"이라는 말 대신 "⚡ 에너지"라고 써.
- **설명서는 지금 코드 기준으로 만들어.** 숫자를 지어내지 말고, 아래 파일에서 확인해서 써. 아래 숫자는 처음 값이고, 부모님이 보호자 공간에서 바꿨을 수 있어. 그러니 "처음 값" 또는 "보통"이라고 적어.
  - 마을 규칙: `lib/village.ts`(`VILLAGE_DEFAULT`, `CRAFT_INFO`, `HABITAT_INFO`)
  - 꾸미기 재료: `lib/village-decor.ts`(`DECOR_INFO`)
  - 열매나무·제작대·레벨·도구: `lib/village-craft.ts`(`CRAFT_DEFAULT`), `lib/village-tools.ts`, `lib/village-level.ts`
  - 먹이기: `components/game/bag-tab.tsx`(`FeedDialog`), `lib/game-config.ts`(`POTIONS`, `GROWTH_DEFAULT`)
  - 화면: `components/game/village*.tsx`, 시험용 마을 `/village-demo`
- 화면 캡처는 `npm run dev` → `/village-demo`에서 Playwright로 찍어(저장 안 되는 시험용 마을). 폰 크기 390×844.
- 결과물:
  1. 아이용 `public/guide/village.html`. 앱 안에서 열 수 있게 큰 글씨, 한 장씩 넘기는 방식.
  2. 부모용 `docs/village-guide-parent.md`
  3. 마을 위쪽 ❓ 옆에 "📘 설명서" 버튼을 달아서 아이용 설명서를 열기
- **아이 기록을 지우거나 바꾸는 코드는 절대 넣지 마.** 이번 일은 설명서와 버튼만이야.
- 끝나면 `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`를 통과시키고, `lib/version.ts`에 한 줄 넣어.

## 설명서에 넣을 내용 (지금 게임의 실제 규칙)

### 0. 마을은 언제 열려?
- 오늘 **일일미션을 다 풀면** 열려. 문제은행을 다 풀었으면 복습 미션을 끝내도 열려.
- 첫 화면 전설 지도 아래 **🏡 포켓몬 마을** 칸을 눌러 들어가.
- 움직이기는 아래 **화살표 버튼 ▲◀▶▼**. 서준이가 걷고 파트너가 따라와.
- 나가기는 위쪽 **"나가기"** 버튼. 폰의 뒤로 가기는 막아 두었어.

### 1. 누를 수 있는 것 (노랗게 반짝이는 곳)
| 무엇 | 누르면 | 하루에 |
|---|---|---|
| 땅에 떨어진 재료 | 그 칸으로 **걸어가면** 저절로 주워 | 3개 |
| 🪨 회색 바위 | 돌멩이를 캐 | 5개 |
| 🍎 열매나무 | 열매를 따 | 나무마다 1개 |
| 🔨 제작대(줄무늬 지붕 가게) | 볼·묘목 만들기 창 | 제한 없음 |
| 📮 우편함(깃발이 서 있으면) | 철 택배 받기 | 택배가 왔을 때 |
| 🐾 손님 포켓몬 | 말 걸기, 가끔 열매 선물 | 손님마다 1번 |
| 🦋🐞🐝 날아다니는 벌레 | 벌레잡기(잠자리채가 있을 때) | 도구가 닳을 때까지 |
| 물가에서 "🎣 낚시하기" 버튼 | 낚시(낚싯대가 있을 때) | 도구가 닳을 때까지 |
| 🔒 노란 팻말 | 열쇠로 땅 열기 | 열쇠가 있을 때 |

### 2. 재료는 어디서 나와?
- 재료 6가지: 풀잎·물방울·꽃잎·나뭇가지·돌멩이·진흙. 종류마다 처음 값 20개까지 가질 수 있어.
- 나오는 곳:
  - 문제 정답: 첫 시도에 맞히면 30% 확률로 1개
  - 일일미션 끝: 2개
  - 마을에서 줍기: 하루 3개
  - 바위 캐기: 돌멩이만, 하루 5개
  - 낚시: 물방울·진흙
  - 벌레잡기: 꽃잎·풀잎
- 공부 재료:
  - **철:** 트레이너 훈련을 열심히 한 주에 우편함으로 와. 주 합계 5 이상이면 2개, 3 이상이면 1개.
  - **반짝돌:** 이틀 뒤 복습 문제를 첫 시도에 맞히면 1개
- 열매는 상자, 선물, 열매나무, 손님, 낚시·벌레잡기에서 나와. 종류마다 99개까지 가질 수 있어.

### 3. 🔨 만들기 / 🎒 가방 (마을 아래 버튼)
- **🔨 만들기**는 재료로 만들기만 하는 곳이야. 칸은 네 개야.
  - 🌱 서식지: 풀숲 = 풀잎 2, 물웅덩이 = 물방울 2, 꽃밭 = 꽃잎 2
  - 🎨 꾸미기: 꽃·덤불·버섯·연잎·그루터기·울타리·화분·꽃 상자·벤치·작은 나무·바위
  - ⛰️ 땅: 연못 칸 = 물방울 2, 흙길 = 진흙 1, 돌길 = 돌멩이 2
  - 🧰 도구: 낚싯대 = 나뭇가지 3 + 풀잎 2, 잠자리채 = 나뭇가지 2 + 꽃잎 2
  - 재료 수는 `DECOR_INFO`에서 확인해.
- 만든 것은 **🎒 가방**에 들어가. 가방에서 눌러야 마을에 **놓을** 수 있어.
  - 밭 물건은 반짝이는 밭 칸에 놓아.
  - 꾸미기와 땅은 반짝이는 풀밭에 놓아.
- 가방에는 재료, 철, 반짝돌, 묘목, 만든 볼(눌러서 열기), 도구 남은 횟수, 열매 개수가 다 보여.
- 마을에 놓은 물건을 다시 누르면 가방으로 돌아와.

### 4. 서식지와 손님
- 밭(점선 네모 4칸)을 채우면 서식지가 돼.
  - 초록 풀숲 = 풀숲 4 → 풀 타입 손님
  - 물가 = 풀숲 2 + 물웅덩이 2 → 물 타입 손님
  - 꽃밭 = 꽃밭 4 → 벌레·페어리 타입 손님
- **다음 날부터** 서식지마다 손님 1마리가 와. 손님은 도감 "만남"이고, 내 포켓몬이 되는 건 아니야.

### 5. 열매나무 · 제작대
- 열매나무는 미션을 끝낸 날 나무마다 1개 열려. 안 따면 다음 날 사라져(벌칙은 없어).
- 묘목(열매 5 + 돌멩이 2)을 심으면 다음 날부터 열매가 열려. 처음 마을은 3그루까지, 땅을 열면 자리가 늘어나.
- 제작대 레시피(열매는 한 종류만 셈):
  - 몬스터볼 = 열매 10 + 돌멩이 3
  - 슈퍼볼 = 열매 30 + 돌멩이 5 + 철 2
  - 하이퍼볼 = 열매 99 + 반짝돌 1
- 만든 볼을 열면 **아직 못 만난 포켓몬**이 나와.
- 재료가 모자라면 버튼이 흐려지고, 누르면 무엇이 몇 개 모자란지 알려 줘.

### 6. 🎣 낚시 · 🦋 벌레잡기
- 도구는 **15번** 쓰면 부서져. 놓쳐도 1번 닳아. 부서지면 다시 만들면 돼.
- 낚시: 물가에 서면 "🎣 낚시하기" 버튼이 나와. 찌가 **퐁!** 하고 들어가면 바로 "당겨!". 빠르거나 늦으면 놓쳐.
- 벌레잡기: 벌레를 누르고, 움직이는 화살표가 **초록 칸**에 올 때 "휘둘러!"
- 잡으면 재료를 받고(10%는 열매), 15%는 포켓몬을 만나(도감 만남, 처음이면 ⭐3).

### 7. 마을 레벨 · 🔑 열쇠
- 마을에서 일을 하면 ⭐ 별을 받아. 마을 위쪽 막대가 보여 줘.
  - 새 손님 3
  - 손님 온 서식지마다 2
  - 물건 만들기 1
  - 볼·묘목 만들기 2
  - 열매 따기 1
- 레벨이 오르면 **열쇠 1개**. 지금 열린 땅에 붙은 🔒 땅(왼쪽·오른쪽·아래) 중 하나를 골라 열어. 모두 15구역이야.
- 필요한 별: 레벨 2까지 50, 레벨 3까지 120, 그 뒤 레벨마다 40씩 더.
- ❓ 버튼으로 안내를 다시 볼 수 있어.

### 8. 🍎 먹이기 (마을이 아니라 첫 화면)
- 첫 화면 위 탭 **🎒 가방**에서 열매나 상처약을 누르고, 먹일 포켓몬을 골라.
- 먹이면:
  - 그 열매의 속성 ⚡ 에너지 +5 (상처약은 모든 속성 +5)
  - 그 포켓몬 💗 +5
  - ★ 배틀 힘 +1
- 💗와 에너지가 모이면 도감에서 진화할 수 있어.
- 다 진화하고 배틀 힘이 최고인 포켓몬에게는 "이미 최고예요"라고 나와.
- 마을 가방의 열매 칸은 **보기만** 해. 열매는 볼 만들기에도 쓰니까 어디에 쓸지는 아이가 골라.

### 9. 실수로 나가졌을 때
- 화면을 당겨서 새로고침되는 것과 폰의 뒤로 가기는 막아 두었어. 홈 버튼은 막을 수 없어.
- 마을에 있다가 새로고침되면 다시 마을로 돌아와.
- 포켓로그는 웨이브마다 저장돼서, 다시 들어가 "이어하기"를 누르면 돼.
