# 설명서 만들기 프롬프트 (개발 챗방에 그대로 붙여 넣기)

> 2026-11-14 마을 규칙 수정 반영본(방명록·🏠 마을점수·열매 섞어 쓰기·반짝돌·철, 🔮 제작대는 볼만·묘목은 🔨 만들기로). 숫자는 이 날 코드에서 다시 확인함.

---

포켓몬 배움 탐험대(저장소 `i20091119-ai/2026poketquiz`, 작업본 `claude/vibrant-bell-ru08mi`)의 **포켓몬 마을 설명서**를 만들어 줘.

## 누가 읽나
- **아이용(초등 1학년):** 아이가 "뭘 누르는지, 뭘 줍는지, 뭘 쓰는지, 재료는 어디서 나오는지" 헷갈려 해. 한 장에 한 가지만, 그림(실제 게임 화면 캡처)과 아주 짧은 문장으로.
- **부모용:** 같은 내용을 한 장짜리 표로. 숫자(하루 몇 번, 몇 개)와 보호자 공간에서 바꾸는 곳까지.

## 지켜 줄 것
- 아이용 문장은 초1 눈높이로 써.
  - 한 문장 15자 안팎, 반말("~해 봐", "~하면 돼"), 어려운 낱말 금지
  - "스탯" 대신 "⚡ 에너지"
  - "수련"이나 "집 공부" 대신 **"트레이너 훈련"**(아이 화면 이름)
- **마을 쪽 설명에는 ⭐·★ 기호를 쓰지 마.** 마을 점수는 **🏠 마을점수**야. ★는 포켓몬의 "배틀 힘"이라 헷갈려.
- **숫자는 반드시 지금 코드에서 다시 확인해서 써.** 아래 숫자는 처음 값이고, 부모님이 보호자 공간에서 바꿨을 수 있으니 "처음 값" 또는 "보통"이라고 적어. 확인할 곳:
  - 마을 규칙: `lib/village.ts`(`VILLAGE_DEFAULT`, `CRAFT_INFO`, `HABITAT_INFO`)
  - 꾸미기 재료: `lib/village-decor.ts`(`DECOR_INFO`)
  - 열매나무·제작대·마을점수·레벨·반짝돌·철·도구: `lib/village-craft.ts`(`CRAFT_DEFAULT`, `recipeCost`), `lib/village-tools.ts`, `lib/village-level.ts`
  - 방명록: `lib/village-guestbook.ts`, `components/game/village-guestbook.tsx`
  - 먹이기: `components/game/bag-tab.tsx`(`FeedDialog`), `lib/game-config.ts`(`POTIONS`, `GROWTH_DEFAULT`)
  - 화면: `components/game/village*.tsx`, 시험용 마을 `/village-demo`
- 아이용 HTML의 글자는 낱말 중간에서 줄이 안 끊기게 `word-break: keep-all`(+ `overflow-wrap: break-word`)을 꼭 넣어.
- 화면 캡처는 `npm run dev`로 띄운 뒤 `/village-demo`에서 Playwright로 찍어. 저장 안 되는 시험용 마을이야. 크기는 폰 크기 390×844로.
- 결과물:
  1. 아이용 `public/guide/village.html`: 앱 안에서 열 수 있게 큰 글씨, 한 장씩 넘기기
  2. 부모용 `docs/village-guide-parent.md`
  3. 마을 위쪽 ❓ 옆에 "📘 설명서" 버튼을 달아 아이용 설명서를 열기
- **아이 기록을 지우거나 바꾸는 코드는 절대 넣지 마.** 이번 일은 설명서와 버튼만이야.
- 끝나면 `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`를 통과시키고 `lib/version.ts`에 한 줄 넣어.

## 설명서에 넣을 내용 (지금 게임의 실제 규칙)

### 0. 마을은 언제 열려?
- 오늘 **일일미션을 다 풀면** 열려. 문제은행을 다 풀었으면 복습 미션을 끝내도 열려.
- 첫 화면 전설 지도 아래 **🏡 포켓몬 마을** 칸을 눌러 들어가.
- 움직이기: 아래 **화살표 버튼 ▲◀▶▼**. 서준이가 걷고 파트너가 따라와.
- 나가기: 위쪽 **"나가기"** 버튼. 폰의 뒤로 가기는 막아 두었어.

### 1. 누를 수 있는 것 (노랗게 반짝이는 곳)
| 무엇 | 누르면 | 하루에 |
|---|---|---|
| 땅에 떨어진 재료 | 그 칸으로 **걸어가면** 저절로 주워 | 3개 |
| 🪨 회색 바위 | 돌멩이를 캐 | 5개 |
| 🍎 열매나무 | 열매를 따 | 나무마다 1개 |
| 🔮 제작대(줄무늬 지붕 가게) | 볼 만들기 창 (아래 🔮 제작대 버튼과 같은 창) | 제한 없음 |
| 📮 우편함(깃발이 서 있으면) | 철 택배 받기 | 택배가 왔을 때 |
| 🐾 손님 포켓몬 | 말 걸기. 좋아하는 것을 알려 주고, 가끔 열매 선물(33%) | 손님마다 1번 |
| 🦋🐞🐝 날아다니는 벌레 | 벌레잡기(잠자리채가 있을 때) | 도구가 닳을 때까지 |
| 물가의 "🎣 낚시하기" 버튼 | 낚시(낚싯대가 있을 때) | 도구가 닳을 때까지 |
| 🔒 노란 팻말 | 열쇠로 땅 열기 | 열쇠가 있을 때 |

마을 아래 버튼은 **[🔮 제작대] [🔨 만들기] [📖 방명록] [🎒 가방]**이야. 🔮 제작대는 **볼만** 만드는 곳이고, 나머지(서식지 물건·꾸미기·땅·도구·열매나무 묘목)는 🔨 만들기에서 만들어.

### 2. 재료는 어디서 나와?
- 재료는 6가지야: 풀잎·물방울·꽃잎·나뭇가지·돌멩이·진흙. 종류마다 처음 값 20개까지 가질 수 있어.
  - 문제 정답: 첫 시도에 맞히면 30% 확률로 1개
  - 일일미션 끝: 2개
  - 마을에서 줍기: 하루 3개
  - 바위 캐기: 돌멩이, 하루 5개
  - 낚시: 물방울·진흙
  - 벌레잡기: 꽃잎·풀잎
- **공부로만 얻는 재료**
  - **반짝돌:** 둘 중 하나를 하면 1개를 받아. 둘을 합쳐 **하루 2개까지**야(복습만 하는 날도 같아).
    - ① 이틀 뒤 다시 나온 **복습 문제를 처음에 맞히기**
    - ② 오늘 미션을 **한 번도 안 틀리고** 끝내기
    - 한 번이라도 틀린 날에도 ①은 받을 수 있어.
  - **철:** 우편함 택배로 와. 둘은 따로 받아서 같은 주에 둘 다 받을 수 있어.
    - ① 트레이너 훈련 택배: 그 주 훈련 합계 5 이상이면 2개, 3 이상이면 1개
    - ② 미션 택배: 그 주(월~일)에 미션을 **5일** 끝내면 다음 월요일에 1개
- **열매:** 상자, 선물, 열매나무, 손님, 낚시·벌레잡기에서 나와. 종류마다 99개까지 가질 수 있어.

### 3. 🔨 만들기 / 🎒 가방
- **🔨 만들기**는 재료로 만들기만 하는 곳이야. 칸이 네 개 있어.
  - 🌱 서식지: 풀숲 = 풀잎 2, 물웅덩이 = 물방울 2, 꽃밭 = 꽃잎 2, **🌳 열매나무 묘목 = 열매 5(섞어도 돼) + 돌멩이 2**
  - 🎨 꾸미기: 꽃·덤불·버섯·연잎·그루터기·울타리·화분·꽃 상자·벤치·작은 나무·바위
  - ⛰️ 땅: 연못 칸 = 물방울 2, 흙길 = 진흙 1, 돌길 = 돌멩이 2
  - 🧰 도구: 낚싯대 = 나뭇가지 3 + 풀잎 2, 잠자리채 = 나뭇가지 2 + 꽃잎 2
  - 꾸미기 재료 수는 `DECOR_INFO`에서 확인해.
- 만든 것은 **🎒 가방**에 들어가. 가방에서 눌러야 마을에 **놓을** 수 있어.
  - 밭 물건은 반짝이는 밭 칸에 놓아.
  - 꾸미기 물건과 땅은 반짝이는 풀밭에 놓아.
- 가방에는 재료, 철, 반짝돌, 묘목, 만든 볼(눌러서 열기), 도구 남은 횟수, 열매 개수가 다 보여.
- 마을에 놓은 물건을 다시 누르면 가방으로 돌아와.

### 4. 서식지와 손님
- 밭(점선 네모 4칸)을 채우면 서식지가 돼.
  - 초록 풀숲 = 풀숲 4 → 풀 타입 손님
  - 물가 = 풀숲 2 + 물웅덩이 2 → 물 타입 손님
  - 꽃밭 = 꽃밭 4 → 벌레·페어리 타입 손님
- **다음 날부터** 서식지마다 손님 1마리가 와.
- 손님은 내 포켓몬이 아니야. **📖 방명록에 적혀.** 전설·환상 포켓몬은 손님으로 오지 않아.

### 4-1. 📖 방명록 (새로 한 장 만들기)
- 마을 아래 **📖 방명록** 버튼을 눌러 봐.
- 마을에 놀러 온 손님, 낚시나 벌레잡기에서 만난 포켓몬이 적혀.
- 포켓몬을 누르면 이런 게 보여.
  - **처음 온 날**
  - **온 횟수:** 올 때마다 🐾 발자국 도장이 하나씩 찍혀. 하루에 한 번만 찍혀.
  - **알아낸 것:** 손님에게 말을 걸면 처음엔 **좋아하는 열매**, 다음엔 **좋아하는 물건**을 알려 줘.
  - **들은 말**
- 아직 안 온 포켓몬은 "?" 빈칸이야.
- 예전에 도감에 "만남"으로 있던 손님도 방명록으로 옮겨 왔어. 그런 손님은 처음 온 날이 "예전에"로 보여.
- 방명록에 적힌 포켓몬은 제작 볼에서 먼저 나와(5번).

### 5. 열매나무 · 🔮 제작대
- **열매나무:** 미션을 끝낸 날 나무마다 1개 열려. 안 따면 다음 날 사라져(벌칙은 없어).
- **묘목:** 🔨 만들기 → 🌱 서식지 칸에서 열매 5 + 돌멩이 2로 만들어. 🎒 가방에서 "묘목 심기"를 누르고 빈 나무 자리에 심으면 다음 날부터 열매가 열려.
  - 처음 마을에는 3그루까지 심을 수 있어. 땅을 열면 자리가 늘어나.
- **🔮 제작대 레시피(볼만)** — **열매는 아무거나 섞어도 돼.** 많이 가진 열매부터 자동으로 골라 두고, +/−로 바꿀 수 있어.
  - 몬스터볼 = 열매 10 + 돌멩이 3 + 반짝돌 1
  - 슈퍼볼 = 열매 30 + 돌멩이 5 + 철 2
  - 하이퍼볼 = 열매 99 + 반짝돌 1
- 만든 볼을 열면 **아직 없는 포켓몬**이 나와.
  - **마을에서 만난 포켓몬(방명록)이 먼저 나와.**
  - 볼마다 나오는 포켓몬이 달라: 몬스터볼 = 보통, 슈퍼볼 = 조금 드묾, 하이퍼볼 = 드묾
  - 가끔 이로치가 나와: 몬스터볼 2%, 슈퍼볼 4%, 하이퍼볼 7%
- 재료가 모자라면 버튼이 흐려져. 누르면 무엇이 몇 개 모자란지 알려 줘.

### 6. 🎣 낚시 · 🦋 벌레잡기
- 도구는 **15번** 쓰면 부서져. 놓쳐도 1번 닳아. 부서지면 다시 만들면 돼.
- **낚시:** 물가에 서면 "🎣 낚시하기" 버튼이 나와. 찌가 **퐁!** 하고 들어가면 바로 "당겨!". 너무 빠르거나 늦으면 놓쳐.
- **벌레잡기:** 벌레를 누르고, 움직이는 화살표가 **초록 칸**에 올 때 "휘둘러!"
- 잡으면 재료를 받아. 10%는 재료 대신 열매가 나와.
- 15%는 포켓몬을 만나. 만난 포켓몬은 **📖 방명록에 적혀.** 처음 만난 포켓몬이면 🏠 마을점수 3을 받아.

### 7. 🏠 마을점수 · 마을 레벨 · 🔑 열쇠
- 마을에서 일을 하면 **🏠 마을점수**를 받아. 마을 위쪽 막대에 "🏠 지금/다음"으로 보여.
  - 처음 보는 손님 3
  - 손님이 온 서식지마다 2
  - 물건 만들기 1
  - 볼·묘목 만들기 2
  - 열매 따기 1
- 레벨이 오르면 **🔑 열쇠 1개**를 받아. 지금 열린 땅에 붙은 🔒 땅(왼쪽·오른쪽·아래) 중 하나를 골라 열어. 마을은 모두 15구역이야.
- 필요한 마을점수(처음 값): 레벨 2까지 50, 레벨 3까지 120, 그 뒤 레벨마다 40씩 더.
- 마을 위쪽 ❓ 버튼으로 안내를 다시 볼 수 있어.

### 8. 🍎 먹이기 (마을이 아니라 첫 화면)
- 첫 화면 위 탭 **🎒 가방**에서 열매나 상처약을 누르고, 먹일 포켓몬을 골라.
- 먹이면 이렇게 올라(이건 마을이 아니라 포켓몬 이야기라 배틀 힘 기호 ★를 써도 돼).
  - 그 열매의 속성 ⚡ 에너지 +5 (상처약은 모든 속성 +5)
  - 그 포켓몬 💗 +5
  - 배틀 힘 ★ +1
- 💗와 에너지가 모이면 도감에서 진화할 수 있어. 다 진화하고 배틀 힘이 최고인 포켓몬은 "이미 최고예요"라고 나와.
- 마을 가방의 열매 칸은 **보기만** 하는 곳이야. 열매는 볼 만들기에도 쓰니까 어디에 쓸지는 아이가 골라.

### 9. 실수로 나가졌을 때
- 화면을 당겨서 새로고침되는 것과 폰의 뒤로 가기는 막아 두었어. 홈 버튼은 막을 수 없어.
- 마을에 있다가 새로고침되면 다시 마을로 돌아와.
- 포켓로그는 웨이브마다 저장돼. 다시 들어가서 "이어하기"를 누르면 돼.
