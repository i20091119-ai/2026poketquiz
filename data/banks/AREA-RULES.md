# 퀴즈 영역 확정안 · 출제 유의점 (아이 엄마, 2026-09-28)

앱의 영역 목록은 `lib/game-config.ts`의 `SUBJECT_AREAS`에 같은 글자로 들어 있습니다. 시트의 "영역" 칸에는 아래 이름을 **글자 그대로**(띄어쓰기·가운뎃점 포함) 적고, 빈칸은 '기타'로 묶입니다.

## 1. 과목별 영역
| 과목 | 영역 | 기준 |
|---|---|---|
| 국어 | 받침·맞춤법 / 낱말 뜻 / 흉내말·반대말 / 부호·띄어쓰기 / 내용 확인 / 생각·까닭 | 글자 → 낱말 → 문장 → 글 |
| 수학 | 수·계산 / 규칙 / 모양·측정 / 분류·자료 | 2022 개정 4영역 |
| 영어 | 알파벳 / 파닉스 / 사이트워드 / 기본 단어 / 문장 만들기 | 학원 과제 + 저학년 기초 |
| 한자 | 숫자 / 요일·자연 / 방향·위치 / 사람·가족 / 학교·나라 / 색·크기·기타 | 한자능력검정 8급 50자 |
| 역사 | 선사·고조선 / 삼국·남북국 / 고려 / 조선 / 근현대 / 문화·풍속 | 한국사능력검정 기본(4~6급) |
| 상식 | 동식물 / 날씨·계절 / 몸·안전 / 동네·규칙 / 음악 / 미술 | 초1 통합교과 수준 |

## 2. 공통 출제 규칙
- 과목별 주 100문제, 오지선다. 정답 번호 1~5 무작위, 번호별 고른 분포.
- 속성: 과목별 3개를 과목 안에서 고르게 배분.
- 보기 5개: 같은 형식, 비슷한 길이, 정답만 눈에 띄지 않게. 오답은 아이가 실제로 헷갈릴 만한 것.
- 해설: 초1이 읽을 수 있는 1~2문장. 같은 주 안 중복 문항 금지, 출제 후 중복·오류 교차 점검. 그림이 필요한 문항 지양.

## 3. 과목별 유의점 (요약)
- **국어**: 받침·맞춤법은 소리를 [ ]로 표기(음식을 → [음시글]), 오답은 소리 나는 대로 쓴 형태. 낱말 뜻은 반드시 문장 안에서 제시. 흉내말·반대말은 짝이 분명한 반대말만, 소리 흉내·모양 흉내 구분. 부호·띄어쓰기는 낱말 단위·조사 붙여 쓰기까지. 내용 확인·생각·까닭은 2~4문장 글 제시(내용 확인은 답이 글에 그대로, 생각·까닭은 생각해야 나오되 정답 하나). 현재 교과(1-2 글쓴이가 하고 싶은 말, 겹받침·쌍받침) 우선.
- **수학**: 수·계산(100까지, 가르기·모으기, 10 만들기, 덧셈·뺄셈; 오답은 흔한 실수값), 규칙(●○·▲■·수 배열), 모양·측정(비교 표현 중심, cm 단위 제외, 시각은 몇 시·몇 시 30분까지), 분류·자료(기준이 하나로 분명). **서술형 유형 주 100문제 중 30문제**: 빈칸 문장 / 틀린 곳 찾기(보기1~5 = ㉠~㉤ 순서 고정, 틀린 단계를 문항마다 다르게) / 알맞은 식 / 이유 고르기. 풀이 3~5줄 이내. 영역 칸은 문제 내용 기준.
- **영어**: 알파벳(b·d, p·q 활용), 파닉스(첫소리·단모음·이중자음, 소리를 한글로 적지 않고 "cat과 같은 소리로 시작하는 낱말은?" 형태), 사이트워드(문장 속 빈칸), 기본 단어(양방향), 문장 만들기(학원 과제 파일 우선, 순서 바른 문장·빈칸, 대문자·마침표 확인).
- **한자**: 8급 50자 밖 한자는 보기에도 금지(上·下는 7급). 배정: 숫자 一二三四五六七八九十萬 / 요일·자연 日月火水木金土山 / 방향·위치 東西南北中外 / 사람·가족 父母兄弟女人寸 / 학교·나라 學校敎室先韓國民軍王門 / 색·크기·기타 白靑大小長年生. 형태: 독음·훈음·한자 고르기·한자어 읽기(父母·先生·校門 등). 훈음은 검정 표기(메 산, 쇠 금/성 김). 金처럼 음이 둘인 한자는 문장으로 구분.
- **역사**: 선사·고조선(현재 진도, 당분간 비중 높게), 삼국·남북국(진도에 맞춰 확대, 연도 암기 지양, 인물·유물·사건 연결), 고려(건국·대외 항쟁·인쇄술·청자), 조선(건국·세종·한글·임진왜란·실학), 근현대(개항·독립운동·광복·6·25), 문화·풍속(세시풍속·민속놀이·문화유산·유네스코; 유물·유적의 시대를 묻는 문항은 해당 시대 영역; 용어는 '국가유산'·'문화유산').
- **상식**: 동식물(논란 없는 사실만), 날씨·계절, 몸·안전, 동네·규칙, 음악(악기 이름·분류, 빠르게·느리게, 세게·여리게; 소리 재생 불가 → 이름·생김새·연주 방법 중심), 미술(색 섞기, 모양, 재료·도구 쓰임, 유명 그림은 작가‒작품 연결, 도구 안전).

## 4. 시트 작성
열 순서: 과목, 문제, 보기1~5, 정답, 해설, 속성, 영역. 기존 문제은행은 그대로 쓰이고 영역만 '기타'. 영역 이름을 바꾸면 해당 문제의 영역을 일괄 수정할 수 있음.
