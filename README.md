# 포켓몬 배움 탐험대

아이가 국어·수학·영어·한자·역사·상식 퀴즈를 풀어 **속성 스탯**을 모으고, 그 스탯으로 포켓몬을 진화시키며 도감(전국도감 1025종)을 채우는 학습 게임입니다.
Cloudflare Workers + D1에서 동작합니다.

## 게임 규칙

### 과목과 속성
정답을 맞히면 그 문제에 붙은 속성 스탯과 경험치(+10)를 얻습니다.

| | 스탯 |
|---|---|
| 일일미션 정답 1문제 | 그 속성 +5 |
| 탐험 정답 1문제 | 그 속성 +1 |

일일미션은 과목마다 속성을 돌아가며 내므로(과목당 하루 3문제 = 속성마다 1문제씩), **일일미션만 꾸준히 풀어도 일주일에 한 번 이상 진화**할 수 있습니다.
- 속성 하나에 일주일 동안 약 28점이 쌓입니다(정답률 80% 기준).
- 7일 동안 정답률 80%로 시뮬레이션한 결과, 시작 포켓몬 첫 진화가 일주일 안에 가능했습니다(59/60, 상자 보상 제외). 이 시뮬레이션은 `lib/game-engine.test.ts`에 테스트로 들어 있습니다.

| 과목 | 계열 | 속성 |
|---|---|---|
| 국어 | 마음과 빛 | 노말 · 에스퍼 · 페어리 |
| 수학 | 광물과 기계 | 전기 · 강철 · 바위 |
| 영어 | 물과 하늘 | 물 · 얼음 · 비행 |
| 한자 | 힘과 불 | 불꽃 · 격투 · 드래곤 |
| 역사 | 어둠과 옛것 | 고스트 · 악 · 독 |
| 상식 (사회/과학) | 자연 | 풀 · 벌레 · 땅 |

비슷한 계열의 속성 3개씩을 한 과목에 묶었고, 18속성을 모두 한 번씩 씁니다. 일일미션에서 매일 모든 과목, 모든 속성이 나오므로 어떤 포켓몬을 골라도 스탯이 고르게 오릅니다. 자주 틀리는 과목이 있으면 그 과목 속성 포켓몬의 진화가 늦어집니다.

### 진화
**진화 후 포켓몬의 속성**을 모으면 진화할 수 있고, 진화하면 그 스탯을 소모합니다. 진화에는 경험치가 들지 않습니다. 대신 첫 화면의 "스탯으로 바꾸기"로 경험치 50을 원하는 속성 스탯 +5로 바꿀 수 있습니다(`EXP_EXCHANGE`). 모은 경험치 전체가 500 쌓일 때마다 몬스터볼 3개 중 하나를 고르는 선물도 받습니다(`EXP_GIFT`).

| 진화 | 속성 2개 | 속성 1개 |
|---|---|---|
| 1단계 → 2단계 | 첫째 10 + 둘째 5 | 15 |
| 2단계 → 3단계 | 첫째 25 + 둘째 12 | 35 |

예: 꾸왁스 → 아꾸왁(물 15, 영어) → 웨이니발(물 25 + 격투 12, 영어 + 한자). 나오하는 상식(풀) + 역사(악), 뜨아거는 한자(불꽃) + 역사(고스트)로 진화합니다. 이브이처럼 진화가 여러 갈래면 원하는 모습을 고릅니다.

### 메뉴
- **첫 화면:** 파트너 포켓몬, 경험치, 18속성 스탯을 보여줍니다. 처음에는 나오하·뜨아거·꾸왁스 중 하나를 고릅니다.
- **일일미션 사탕:** 오늘의 미션 18문제를 다 풀면(틀린 것 포함) 파트너 포켓몬에게 포켓로그 사탕 1개, 모두 맞히면 3개를 보냅니다(`DAILY_CANDY`). 포켓로그를 켜면 파트너의 진화 전 첫 모습 스타터에 들어가고, 게임 안에서 패시브 특성 해제·스타터 비용 낮추기에 씁니다. 게임 안에서 원래 방식으로 모이는 사탕과 합쳐집니다.
- **탭 묶음 두 개:** 위는 [일일미션 | 탐험 | 포켓몬 도감 | 가방], 그 아래에 항상 보이는 [배틀 | 이벤트]가 있습니다(처음엔 배틀 탭). 배틀 탭은 포켓로그(`/battle/`)로 가는 문이고, 이벤트 탭은 아직 "곧 열려요"만 있습니다.
- **일일미션:** 문제은행에서 과목별 3문제씩, 총 18문제를 냅니다. 과목 안에서는 속성이 고르게 돌아가도록 뽑습니다.
  - 문제마다 **기회는 3번**(처음 + 다시 풀기 2번)입니다. 3번 모두 틀리면 정답과 해설을 보여주고 다음 문제로 넘어갑니다.
  - 18문제를 다 풀면 맞힌 개수에 따라 랜덤상자를 고릅니다(하루 1회).
    - **18개 모두 맞힘:** 3개 중 **2개**
    - **15개 이상 맞힘:** 3개 중 **1개**
    - 14개 이하: 상자 없음
  - 상자 내용물
    - 아이템: 열매 6종·상처약 (아래 표). 가방에 들어갑니다.
    - 볼: 몬스터볼, 슈퍼볼, 하이퍼볼, 마스터볼. 볼을 누르면 랜덤 포켓몬이 나오고 도감에 저장됩니다.
  - 한 번이라도 틀린 문제(다시 풀어서 맞힌 문제 포함)는 다음 날부터 일일미션에 **가장 먼저** 다시 나옵니다. 문제를 뽑는 순서는 전에 틀린 문제 → 안 푼 문제 → 맞힌 문제입니다.
- **탐험:** 과목을 고르면 아직 맞히지 못한 문제가 나옵니다.
  - 문제마다 **기회는 한 번**입니다. 틀린 문제는 "안 푼 문제"로 문제은행에 남고, 그날은 더 나오지 않다가 **다른 날** 다시 나옵니다.
  - 오늘의 일일미션에 들어 있는 문제는 탐험에서 빠집니다. 하루에 같은 문제를 두 번 풀지 않게 하기 위해서입니다.
  - 과목 하나를 모두 맞히면 선물(아이템) 3개 중 1개를 고릅니다. 주로 그 과목의 열매가 나옵니다.
  - 모든 과목을 마스터하면 럭셔리볼 3개 중 1개를 고릅니다. 50% 확률로 희귀·전설·환상 포켓몬이 나옵니다.
- **포켓몬 도감:** 가진 포켓몬마다 진화에 필요한 스탯과 진화 버튼이 있습니다. 전체 도감 목록도 여기서 봅니다.
- **가방:** 열지 않은 볼과 아이템이 모입니다. 볼을 누르면 포켓몬을 만나고, 아이템은 포켓몬을 골라 먹이면 적힌 속성 스탯이 오릅니다. 고른 포켓몬의 진화까지 얼마나 남았는지도 보여 줍니다.

| 아이템 | 효과 |
|---|---|
| 사과열매 | 풀·벌레·땅 +5 |
| 얼음열매 | 물·얼음·비행 +5 |
| 불꽃열매 | 불꽃·격투·드래곤 +5 |
| 번개열매 | 전기·강철·바위 +5 |
| 유령열매 | 고스트·악·독 +5 |
| 별빛열매 | 노말·에스퍼·페어리 +5 |
| 상처약 (드묾) | 모든 속성 +5 |
- **공통:**
  - 이미 맞힌 문제를 나중에 틀리면 다시 "안 푼 문제"가 됩니다.
  - 이미 가진 포켓몬이 또 나오면 그 속성 스탯 +5로 바뀝니다.

확률과 수치는 모두 `lib/game-config.ts` 한 곳에서 바꿀 수 있습니다.

## 보호자 공간 (`/parent`)
`PARENT_PASSWORD` 비밀번호로 로그인합니다.
- **아이 현황:** 경험치, 스탯, 도감 수, 과목별 진도(다시 풀 문제 수 포함), 많이 틀린 문제
- **개발자 메뉴:** ① 버전 — `lib/version.ts`의 버전 이름 + 올린 날짜(빌드 때 자동) + 이번에 바뀐 것. ② 시뮬레이션 — 보호자가 아이처럼 앱 전체를 해 봅니다. 아이의 진짜 기록(`game_state` 의 `family`)은 건드리지 않고 시험용 기록(`sim`)을 씁니다. "지금 아이 기록 복사" 또는 "빈 기록"으로 시작하면 그 브라우저에 서명된 쿠키(`pq_sim`, 7일)가 생기고, 아이 화면·포켓로그 API가 모두 시험용 기록을 씁니다. "다음 날로 넘기기"는 `settings.sim_day_offset`을 1씩 올려 시험용 기록의 오늘을 미룹니다(일일미션·포켓로그 새 게임 횟수 초기화 확인용). 아이 화면 맨 위의 보라색 띠를 누르면 보호자 공간으로 돌아옵니다.
- **아이 게임 처음부터 다시 하기:** 항상 맨 아래 칸입니다.
- **기본 학년:** 초1~초6. 문제은행마다 따로 정할 수도 있습니다.
- **주차별 문제은행:** **구글 시트로 문제은행 추가** 버튼 → 시트 링크 붙여 넣기 → 가져온 문제 검토·수정·삭제 → **아이에게 공개**. 공개 중인 은행은 하나이며, 새 은행을 공개하면 이전 은행은 "지난 문제은행"이 됩니다. 링크 없이 빈 문제은행을 만든 뒤 나중에 채울 수도 있습니다.
- **영역별로 보기:** 공개 중인 문제은행 칸에 과목마다 영역별 정답률·틀린 수·최근 5번 결과가 색(초록 잘함/노랑 보통/빨강 약점)으로 보이고, 2번 이상 틀린 문제를 영역별로 묶어 보여줍니다. 약점 영역(최근 5번 중 2번 이상 틀림)은 일일미션에서 그 영역의 다른 문제가 과목당 2문제까지 먼저 나오고, 최근 5번 중 4번 이상 맞히면 보통으로 돌아갑니다(`WEAK_AREA`).
- **하루에 얼마나 했나:** 퀴즈 화면을 보고 있던 시간(아이 화면이 1분마다 `quizTime`으로 보고)과 포켓로그 플레이 시간을 막대그래프로, 최근 7일 또는 4주(주별 합계). 표로도 볼 수 있습니다. 기록은 35일 보관(`ACTIVITY_LOG_DAYS`).
- **도전 이벤트(이벤트 탭):** "도전! 전 과목 올클리어"는 탐험 6과목을 모두 마스터하면 부활권 1장, "일일미션 10일 연속"은 하루도 빠짐없이 일일미션을 다 풀면 랜덤박스 1개(희귀 포켓몬 볼 또는 배틀 추가권)를 줍니다. 아이가 "도전할래!"를 눌러야 시작하고, 끝내면 다시 나오지 않습니다. 희귀 포켓몬 후보는 `lib/rare-pokemon.ts`에서 고칠 수 있어요.
- **부활권:** 포켓로그에서 지면 그 자리에서 "부활권을 쓸까?"가 나오고, 쓰면 포켓몬 모두 체력을 가득 채워 그 웨이브를 다시 싸웁니다. 진행 중인 판이 없으면 배틀 탭에서 지난번 진 판을 되살릴 수 있어요. 새 게임 횟수는 쓰지 않고, 쉬는 시간·시간 제한은 그대로입니다.
- **포켓로그 ✕ 버튼:** 게임 화면 오른쪽 위 ✕를 누르면 "그만할까?"를 묻고, 그만하기를 누르면 저장한 뒤 퀴즈 화면으로 돌아옵니다. 다음에 "계속하기"를 누르면 그 웨이브 처음부터 이어집니다.
- **휴대폰에 앱으로 설치:** 크롬에서 퀴즈 앱을 열고 메뉴(⋮) → "앱 설치"(또는 "홈 화면에 추가")를 누르면 "배움탐험대" 아이콘이 생깁니다. 주소창 없이 열리고, 배틀로 넘어가도 같은 창 안에서 열립니다. 아이폰은 사파리 공유 버튼 → "홈 화면에 추가".
- **보호자 선물:** 보호자 공간 "선물 보내기"에서 엄마/아빠, 이유(숙제·독서·정리정돈·운동·직접 입력), 크기(작은/보통/큰), 한 줄 편지를 골라 보냅니다. 아이가 앱을 열면 팝업이 뜨고, 열 때 둘 중 하나를 고릅니다(작은: 경험치 +30 또는 열매 1개, 보통: 랜덤상자 1개 또는 포켓로그 사탕 3개, 큰: 몬스터볼 1개 또는 배틀 추가권 1장). 한도는 작은 하루 2개·보통 하루 1개·큰 일주일 1개이고 보호자 공간에서 바꿀 수 있습니다.
- **아이 답장:** 선물을 받은 뒤 새싹 동글이 스티커 5개 중 하나와 30자 이내 글로 답장합니다(선물 하나에 한 번, "나중에"를 누르면 선물 탭에서). 보호자 공간 맨 위에 "새 답장 N개"가 보이고 기록 표에 답장이 함께 나옵니다.
- **배틀 쉬는 시간:** 보호자 공간 포켓로그 칸에서 요일·시작·끝·이름으로 여러 개 둡니다(처음 값: 일과 시간 월~금 07:30~18:00, 잠자는 시간 매일 22:30~07:30). 그 시간에는 새 게임도 이어하기도 잠기고, 게임 중이면 10분 전에 안내한 뒤 그 전투가 끝나면 저장하고 퀴즈로 돌아옵니다. "오늘만 열어 주기"는 자정에 저절로 풀립니다. 판단은 서버의 한국 시간 기준이며 퀴즈는 막지 않습니다.
- **이로치 도감:** 포켓로그 이벤트에서 받은 색이 다른 포켓몬은 퀴즈 도감에 "블랙레쿠쟈"처럼 색 이름이 붙은 이름과 이로치 그림으로 따로 모입니다. 기본 색 포켓몬은 그대로 퀴즈로 얻을 수 있어요.
- **포켓로그 판 안 진화:** 기본은 막혀 있습니다(레벨이 올라도 진화하지 않고, 진화 아이템도 보상에 안 나옴). 보호자 공간 포켓로그 칸의 "배틀 중 진화 허용"으로 켤 수 있고, 게임에는 1분 안에 반영됩니다.
- **포켓로그 하루 시간 제한:** 기본 제한 없음. 15~90분 중 고르면(`BATTLE_LIMIT_OPTIONS`, `settings.battle_limit_minutes`) 그날 플레이 시간이 차면 새 게임이 막히고, 게임 화면에 '오늘은 여기까지' 안내가 덮여 퀴즈로 돌아갑니다.
- **연습 문제은행 불러오기:** `data/banks/bank1~3.csv`(초1, 과목당 24문제, 영역 포함)를 '검토 중' 상태로 가져옵니다. 과목별 원본은 `data/banks/<과목>.csv`이고 `node scripts/assemble-banks.mjs`로 합칩니다. 테스트가 형식·중복을 검사합니다.
- **문제 채우는 방법**
  - **구글 시트 링크:** 시트 공유를 "링크가 있는 모든 사용자(뷰어)"로 바꾼 뒤 링크를 붙여 넣습니다.
  - **시트 내용 붙여 넣기:** 링크가 안 될 때 구글 시트에서 ⌘A(전체 선택) → ⌘C(복사) 후 창에 ⌘V로 붙여 넣으면 됩니다. CSV 내용을 붙여 넣어도 됩니다.
  - **AI로 만들기:** 연결 자리만 있고 아직 비어 있습니다 (아래 참고). 그 대신 "AI 요청문 복사" 버튼으로 원하는 AI 대화창에서 시트용 문제를 만들 수 있습니다.

### 시트 양식
첫 줄은 제목 줄입니다. 양식 파일은 `public/templates/question-template.csv`에 있고, 보호자 화면에서도 내려받을 수 있습니다.

```
과목,문제,보기1,보기2,보기3,보기4,보기5,정답,해설,속성,영역
```
- **과목:** 국어/수학/영어/한자/역사/상식. `사회`·`과학`은 상식으로, `English`는 영어로 들어갑니다.
- **정답:** 1~5 번호, 또는 정답 보기의 글자
- **속성:** 과목에 맞는 속성 이름(예: 풀). 비우거나 과목에 맞지 않으면 자동으로 정합니다.
- **영역:** 그 문제가 속한 영역 이름(예: 덧셈, 받침·맞춤법). 같은 영역은 글자를 똑같이 적어야 한 묶음이 됩니다. 비우면 '기타'.
- 링크로 가져오기에 실패하면 원인(권한, 엑셀 파일, 인터넷 연결 등)을 알려 주고, 자세한 내용은 `npm run dev`를 켠 터미널에 남깁니다.
- 형식이 틀린 줄은 건너뛰고, 몇 번째 줄이 왜 빠졌는지 화면에 보여줍니다.

### AI 문제 생성 연결하기
`lib/ai-generator.ts`에 연결 자리가 있습니다.
1. `isAiConfigured`가 `true`를 돌려주게 합니다.
2. `generateQuestions`에서 사용할 AI를 호출해, 과목마다 문제 배열을 돌려주게 합니다.
3. API 키는 `npx wrangler secret put <이름>`으로 등록하고, `cloudflare-env.d.ts`에 타입을 추가합니다.

## 로컬 실행
Node.js 22.13 이상이 필요합니다.

```sh
npm install
cp .dev.vars.example .dev.vars          # PARENT_PASSWORD 값을 바꿔 주세요
```

처음 접속하면 샘플 문제은행(초1, 과목별 7문제)이 자동으로 공개됩니다.

## Cloudflare 배포 (인터넷에 올리기)

### 자동으로 올리기 (추천)

작업본(`claude/vibrant-bell-ru08mi`)에 새 버전이 올라오면 GitHub가 검사 → 만들기 → Cloudflare에 올리기 → 올라간 버전 확인까지 스스로 합니다(`.github/workflows/deploy.yml`). 맥에서 따로 할 일이 없습니다.

처음 한 번만 Cloudflare 열쇠(API 토큰)를 GitHub에 넣어 둡니다.
1. Cloudflare → 오른쪽 위 사람 아이콘 → My Profile → API Tokens → Create Token → "Edit Cloudflare Workers" 템플릿 → Use template
2. Permissions에 `Account` · `D1` · `Edit` 한 줄을 추가 → Account Resources는 내 계정 → Continue → Create Token → 나온 토큰 복사
3. GitHub 저장소 → Settings → Secrets and variables → Actions → New repository secret → 이름 `CLOUDFLARE_API_TOKEN`, 값에 토큰 붙여 넣기 → Add secret

보호자 비밀번호(`PARENT_PASSWORD`)는 Cloudflare 화면에서 정합니다: Workers & Pages → poke-quiz → Settings → Variables and Secrets → Add → Type을 Secret으로, 이름 `PARENT_PASSWORD`.

자동 작업이 하는 일: 기록 저장소 `poke-quiz-db`가 없으면 만들고 번호를 채움 → 표 맞추기 → `data/restore.sql`이 있고 아직 안 옮겼으면 옛 기록 옮기기(한 번만, `settings.restored_from`으로 표시) → 올리기 → 올라간 버전 확인. 게임 주소는 Actions 실행 결과의 Summary에 적힙니다.

### 맥에서 직접 올리기 (예비 방법)

맥 터미널에서 게임 폴더로 이동한 뒤 아래 한 줄이면 됩니다. 처음이든, 코드를 고친 뒤 다시 올리든 같은 명령입니다.

```sh
npm run online
```

`scripts/online.mjs`가 아래를 차례로 합니다. 이미 된 단계는 건너뜁니다.
1. Cloudflare 로그인 (처음 한 번 브라우저가 열림)
2. 기록 저장소(D1) `poke-quiz-db` 만들기, `wrangler.jsonc`에 번호 적기
3. 기록 저장소에 표 만들기 (`migrations/`)
4. 게임을 만들어서 올리기 (처음이면 `*.workers.dev` 주소 이름을 물어봄)
5. 보호자 비밀번호(`PARENT_PASSWORD`)가 없으면 입력받아 저장

끝나면 게임 주소와 보호자 공간 주소를 알려 주고 브라우저로 엽니다.
- 비밀번호 바꾸기: `npx wrangler secret put PARENT_PASSWORD`
- (선택) 접속 제한: `*.workers.dev` 주소는 주소를 아는 사람은 누구나 열 수 있습니다. Cloudflare Zero Trust → Access에서 이 Worker에 애플리케이션을 추가하고 가족 이메일만 허용하면, 이메일 인증을 거친 사람만 들어올 수 있습니다.
