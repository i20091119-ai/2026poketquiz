# 포켓몬 배움 탐험대

아이가 국어·수학·영어·한자·역사·상식 퀴즈를 풀어 **속성 스탯**을 모으고, 그 스탯으로 포켓몬을 진화시키며 도감(전국도감 1025종)을 채우는 학습 게임입니다.
Cloudflare Workers + D1에서 동작합니다.

## 게임 규칙

### 과목과 속성
정답을 맞히면 그 문제에 붙은 속성 스탯과 경험치(+10)를 얻습니다.

| | 스탯 |
|---|---|
| 일일미션 정답 1문제 | 그 속성 +5 |
| 탐험 정답 1문제 | 그 속성 +1 |

일일미션은 과목마다 속성을 돌아가며 내므로(과목당 하루 3문제 = 속성마다 1문제씩), **일일미션만 꾸준히 풀어도 일주일에 한 번 이상 진화**할 수 있습니다.
- 속성 하나에 일주일 동안 약 28점이 쌓입니다(정답률 80% 기준).
- 7일 동안 정답률 80%로 시뮬레이션한 결과, 시작 포켓몬 첫 진화가 일주일 안에 가능했습니다(59/60, 상자 보상 제외). 이 시뮬레이션은 `lib/game-engine.test.ts`에 테스트로 들어 있습니다.

| 과목 | 계열 | 속성 |
|---|---|---|
| 국어 | 마음과 빛 | 노말 · 에스퍼 · 페어리 |
| 수학 | 광물과 기계 | 전기 · 강철 · 바위 |
| 영어 | 물과 하늘 | 물 · 얼음 · 비행 |
| 한자 | 힘과 불 | 불꽃 · 격투 · 드래곤 |
| 역사 | 어둠과 옛것 | 고스트 · 악 · 독 |
| 상식 (사회/과학) | 자연 | 풀 · 벌레 · 땅 |

비슷한 계열의 속성 3개씩을 한 과목에 묶었고, 18속성을 모두 한 번씩 씁니다. 일일미션에서 매일 모든 과목, 모든 속성이 나오므로 어떤 포켓몬을 골라도 스탯이 고르게 오릅니다. 자주 틀리는 과목이 있으면 그 과목 속성 포켓몬의 진화가 늦어집니다.

### 진화
**진화 후 포켓몬의 속성**을 모으면 진화할 수 있고, 진화하면 그 스탯을 소모합니다. 경험치는 줄지 않습니다.

| 진화 | 속성 2개 | 속성 1개 |
|---|---|---|
| 1단계 → 2단계 | 첫째 10 + 둘째 5 | 15 |
| 2단계 → 3단계 | 첫째 25 + 둘째 12 | 35 |

예: 꾸왁스 → 아꾸왁(물 15, 영어) → 웨이니발(물 25 + 격투 12, 영어 + 한자). 나오하는 상식(풀) + 역사(악), 뜨아거는 한자(불꽃) + 역사(고스트)로 진화합니다. 이브이처럼 진화가 여러 갈래면 원하는 모습을 고릅니다.

### 메뉴
- **첫 화면:** 파트너 포켓몬, 경험치, 18속성 스탯을 보여줍니다. 처음에는 나오하·뜨아거·꾸왁스 중 하나를 고릅니다.
- **일일미션:** 문제은행에서 과목별 3문제씩, 총 18문제를 냅니다. 과목 안에서는 속성이 고르게 돌아가도록 뽑습니다.
  - 문제마다 **기회는 3번**(처음 + 다시 풀기 2번)입니다. 3번 모두 틀리면 정답과 해설을 보여주고 다음 문제로 넘어갑니다.
  - 18문제를 다 풀면 맞힌 개수에 따라 랜덤상자를 고릅니다(하루 1회).
    - **18개 모두 맞힘:** 3개 중 **2개**
    - **15개 이상 맞힘:** 3개 중 **1개**
    - 14개 이하: 상자 없음
  - 상자 내용물
    - 물약: 상처약 +3, 좋은상처약 +5, 고급상처약 +10. 오르는 속성은 랜덤입니다.
    - 볼: 몬스터볼, 슈퍼볼, 하이퍼볼, 마스터볼. 볼을 누르면 랜덤 포켓몬이 나오고 도감에 저장됩니다.
  - 한 번이라도 틀린 문제(다시 풀어서 맞힌 문제 포함)는 다음 날부터 일일미션에 **가장 먼저** 다시 나옵니다. 문제를 뽑는 순서는 전에 틀린 문제 → 안 푼 문제 → 맞힌 문제입니다.
- **탐험:** 과목을 고르면 아직 맞히지 못한 문제가 나옵니다.
  - 문제마다 **기회는 한 번**입니다. 틀린 문제는 "안 푼 문제"로 문제은행에 남고, 그날은 더 나오지 않다가 **다른 날** 다시 나옵니다.
  - 오늘의 일일미션에 들어 있는 문제는 탐험에서 빠집니다. 하루에 같은 문제를 두 번 풀지 않게 하기 위해서입니다.
  - 과목 하나를 모두 맞히면 물약 3개 중 1개를 고릅니다. 그 과목 속성 중 하나가 오릅니다.
  - 모든 과목을 마스터하면 럭셔리볼 3개 중 1개를 고릅니다. 50% 확률로 희귀·전설·환상 포켓몬이 나옵니다.
- **포켓몬 도감:** 가진 포켓몬마다 진화에 필요한 스탯과 진화 버튼이 있습니다. 열지 않은 볼과 전체 도감 목록도 여기서 봅니다.
- **공통:**
  - 이미 맞힌 문제를 나중에 틀리면 다시 "안 푼 문제"가 됩니다.
  - 이미 가진 포켓몬이 또 나오면 그 속성 스탯 +5로 바뀝니다.

확률과 수치는 모두 `lib/game-config.ts` 한 곳에서 바꿀 수 있습니다.

## 보호자 공간 (`/parent`)
`PARENT_PASSWORD` 비밀번호로 로그인합니다.
- **아이 현황:** 경험치, 스탯, 도감 수, 과목별 진도(다시 풀 문제 수 포함), 많이 틀린 문제
- **기본 학년:** 초1~초6. 문제은행마다 따로 정할 수도 있습니다.
- **주차별 문제은행:** **구글 시트로 문제은행 추가** 버튼 → 시트 링크 붙여 넣기 → 가져온 문제 검토·수정·삭제 → **아이에게 공개**. 공개 중인 은행은 하나이며, 새 은행을 공개하면 이전 은행은 "지난 문제은행"이 됩니다. 링크 없이 빈 문제은행을 만든 뒤 나중에 채울 수도 있습니다.
- **문제 채우는 방법**
  - **구글 시트 링크:** 시트 공유를 "링크가 있는 모든 사용자(뷰어)"로 바꾼 뒤 링크를 붙여 넣습니다.
  - **시트 내용 붙여 넣기:** 링크가 안 될 때 구글 시트에서 ⌘A(전체 선택) → ⌘C(복사) 후 창에 ⌘V로 붙여 넣으면 됩니다. CSV 내용을 붙여 넣어도 됩니다.
  - **AI로 만들기:** 연결 자리만 있고 아직 비어 있습니다 (아래 참고). 그 대신 "AI 요청문 복사" 버튼으로 원하는 AI 대화창에서 시트용 문제를 만들 수 있습니다.

### 시트 양식
첫 줄은 제목 줄입니다. 양식 파일은 `public/templates/question-template.csv`에 있고, 보호자 화면에서도 내려받을 수 있습니다.

```
과목,문제,보기1,보기2,보기3,보기4,보기5,정답,해설,속성
```
- **과목:** 국어/수학/영어/한자/역사/상식. `사회`·`과학`은 상식으로, `English`는 영어로 들어갑니다.
- **정답:** 1~5 번호, 또는 정답 보기의 글자
- **속성:** 과목에 맞는 속성 이름(예: 풀). 비우거나 과목에 맞지 않으면 자동으로 정합니다.
- 링크로 가져오기에 실패하면 원인(권한, 엑셀 파일, 인터넷 연결 등)을 알려 주고, 자세한 내용은 `npm run dev`를 켠 터미널에 남깁니다.
- 형식이 틀린 줄은 건너뛰고, 몇 번째 줄이 왜 빠졌는지 화면에 보여줍니다.

### AI 문제 생성 연결하기
`lib/ai-generator.ts`에 연결 자리가 있습니다.
1. `isAiConfigured`가 `true`를 돌려주게 합니다.
2. `generateQuestions`에서 사용할 AI를 호출해, 과목마다 문제 배열을 돌려주게 합니다.
3. API 키는 `npx wrangler secret put <이름>`으로 등록하고, `cloudflare-env.d.ts`에 타입을 추가합니다.

## 에셋 교체
지금 이미지는 모두 임시 SVG입니다. `public/assets/README.md`의 목록에 있는 파일을 같은 이름으로 덮어쓰면 바로 바뀝니다. 경로는 `lib/assets.ts`에서 관리합니다.

포켓몬 이미지는 포켓몬코리아 공식 도감에서 불러옵니다. 실패하면 pokemon.com 이미지, 그다음 임시 이미지를 씁니다.

## 로컬 실행
Node.js 22.13 이상이 필요합니다.

```sh
npm install
cp .dev.vars.example .dev.vars          # PARENT_PASSWORD 값을 바꿔 주세요
npm run db:migrate:local                # 로컬 D1에 표 만들기 (처음 한 번)
npm run dev                             # http://localhost:5173 , 보호자: /parent
```

그 밖의 명령:
- 검사: `npm run lint`, `npm run typecheck`, `npm test`
- 포켓몬 데이터 다시 만들기(PokeAPI): `npm run data:pokedex`

처음 접속하면 샘플 문제은행(초1, 과목별 7문제)이 자동으로 공개됩니다.

## Cloudflare 배포 (인터넷에 올리기)

맥 터미널에서 게임 폴더로 이동한 뒤 아래 한 줄이면 됩니다. 처음이든, 코드를 고친 뒤 다시 올리든 같은 명령입니다.

```sh
npm run online
```

`scripts/online.mjs`가 아래를 차례로 합니다. 이미 된 단계는 건너뜁니다.
1. Cloudflare 로그인 (처음 한 번 브라우저가 열림)
2. 기록 저장소(D1) `poke-quiz-db` 만들기, `wrangler.jsonc`에 번호 적기
3. 기록 저장소에 표 만들기 (`migrations/`)
4. 게임을 만들어서 올리기 (처음이면 `*.workers.dev` 주소 이름을 물어봄)
5. 보호자 비밀번호(`PARENT_PASSWORD`)가 없으면 입력받아 저장

끝나면 게임 주소와 보호자 공간 주소를 알려 주고 브라우저로 엽니다.
- 비밀번호 바꾸기: `npx wrangler secret put PARENT_PASSWORD`
- (선택) 접속 제한: `*.workers.dev` 주소는 주소를 아는 사람은 누구나 열 수 있습니다. Cloudflare Zero Trust → Access에서 이 Worker에 애플리케이션을 추가하고 가족 이메일만 허용하면, 이메일 인증을 거친 사람만 들어올 수 있습니다.

## 폴더 구조

| 경로 | 내용 |
|---|---|
| `app/page.tsx`, `app/game-client.tsx` | 아이 게임 화면 |
| `app/parent/page.tsx`, `components/parent/` | 보호자 공간 |
| `components/game/` | 홈, 미션, 탐험, 도감, 퀴즈, 보상 화면 조각 |
| `app/api/game/` | 게임 API (정답 확인·보상·확률은 모두 서버에서 처리) |
| `app/api/parent/` | 보호자 API (로그인, 문제은행, 시트 가져오기) |
| `lib/game-config.ts` | 과목·속성·확률·진화 비용 설정 |
| `lib/game-engine.ts` | 게임 규칙 (+ `game-engine.test.ts`) |
| `lib/pokedex.ts`, `lib/data/pokedex.json` | 전국도감 데이터와 진화 조건 계산 |

| `lib/ai-generator.ts` | AI 문제 생성 연결 자리 |
| `lib/server/` | D1 저장소, 부모 로그인 |
| `migrations/` | D1 표 구조 |
