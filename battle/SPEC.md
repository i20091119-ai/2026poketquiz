# 포켓로그 포크 사양서 (포켓몬 배움 탐험대 연동)

- 원본: `pagefaultgames/pokerogue` (AGPL-3.0) → 본인 계정으로 포크
- 연동 앱: `i20091119-ai/2026poketquiz` (Cloudflare Workers + D1)
- 원칙: 전투 한 턴 흐름·데미지 공식·웨이브 구성·보상 구조는 원본 그대로. 아래 항목만 변경.

## 1. 출전 포켓몬
- 퀴즈 앱에서 획득한 포켓몬만 스타터로 해제
- 게임 시작 시 퀴즈 앱 `GET /api/my-pokemon` → 전국도감 번호 목록 수신 (포켓로그 `SpeciesId` = 전국도감 번호)
- 수정 위치: `src/system/game-data.ts` 기본 스타터 해제 부분(`defaultStarterSpecies` 반복문) → 수신 목록으로 교체
- 매 실행 시 목록 기준으로 재구성 (로컬 저장된 도감 데이터로 해제 범위가 늘지 않게)
- 시작 레벨: 원본 그대로 Lv.5 (`game-mode.ts` `getStartingLevel`)
- 스타터 포인트 한도: 15 (원본 클래식 10). 위치: `src/ui/utils/starter-select-ui-utils.ts` `getRunValueLimit`

## 2. 포획 금지
- 전투 중 볼 명령 제거: `src/ui/handlers/command-ui-handler.ts`
- 포획 처리 차단: `src/phases/attempt-capture-phase.ts`
- 상점 보상의 볼(몬스터볼·울트라볼·로그볼·마스터볼) → 같은 등급의 다른 상점 아이템 중 무작위로 대체
  - 위치: `src/modifier/init-modifier-pools.ts`

## 3. 돌발 이벤트
- 포켓몬을 주는 이벤트 4종 → 보유 포켓몬 중 하나의 색이 다른 개체(이로치)를 지급
  - `uncommon-breed-encounter.ts`, `the-pokemon-salesman-encounter.ts`, `dancing-lessons-encounter.ts`, `absolute-avarice-encounter.ts` (모두 `src/data/mystery-encounters/encounters/`)
  - 지급 개체는 그 판에서만 사용

## 4. 삭제
- 알 시스템 전체: 알 뽑기, 알 교환권, 알 부화 (`egg.ts`, `egg-hatch-phase.ts`, `egg-lapse-phase.ts` 등, 보상 풀의 알 교환권 포함)
- 유전자쐐기(DNA_SPLICERS): 보상 풀에서 제거
- 게임 모드: 클래식만 유지 (엔드리스·스플라이스드 엔드리스·데일리·챌린지 메뉴 제거)

## 5. 웨이브
- 최종 웨이브 55 (원본 클래식 200). 55 = 원본 고정 전투 라이벌3
- 55웨이브 승리 = 게임 클리어 처리
- 체육관 배치(20·50 또는 30)는 원본대로 판마다 무작위
- 설정값 한 곳에서 관리 (추후 100 → 150 → 200 단계 확대)
- 참고: 1~55 구간 원본 구성 — 10웨이브마다 지역 변경·파티 회복, x0웨이브 보스 포켓몬, 체육관 관장 20·50 또는 30(판마다 무작위), 고정 전투 5 반바지 꼬마·8 라이벌1·25 라이벌2·35 악의 조직 조무래기1·55 라이벌3, 돌발 이벤트 10웨이브부터

## 6. 판 안 진화
- 전투 중 진화는 그 판에서만 유효. 퀴즈 앱 도감·보유 목록에 반영하지 않음

## 7. 시도 횟수
- 새 게임 시작 = 1회, 하루 1회
- 초기화: 매일 자정(한국 시간)
- 횟수는 퀴즈 앱 서버(D1)에서 관리. 새 게임 시작 전 `POST /api/battle/start`로 확인·차감
- 자동 중간 저장, 이어하기 허용 (이어하기는 횟수 차감 없음)
- 자정이 지나도 진행 중인 판은 이어하기 가능

## 8. 데이터 사용량
- 배경음악 압축: 원본 171곡 약 380MB → 모노·저비트레이트 재인코딩 (목표 약 1/3)
  - 에셋 저장소(`pokerogue-assets`)는 포크하지 않고, 빌드 단계(GitHub Actions)에서 ffmpeg로 변환
- "게임 준비하기" 버튼: 와이파이에서 그림·소리 전체를 미리 받아 브라우저 캐시(Cache Storage)에 저장
  - 참고: 원본 `index.html`이 `service-worker.js`를 등록하지만 저장소에 파일 없음 → 새로 작성
- 받은 뒤에는 이미 받은 파일 재다운로드 없음

## 9. 호스팅
- Cloudflare Workers 유료 요금제 (정적 파일 10만 개 한도, 원본 에셋 약 3.2만 개)
- 로그인 없이 브라우저 저장 모드로 동작
- 가족만 접속 가능하도록 접근 제한

## 10. 언어
- 한국어 고정. 설정의 언어 선택 메뉴 제거, 브라우저 언어와 무관하게 `ko` 적용
- 번역 누락 문장 점검: `pokerogue-locales/ko` 기준 전체 13,660개 중 누락 37개, 영어와 동일 108개(HP 등 고유 표기 포함) → 누락분은 직접 번역해 채움, 영어로 대체 표시 금지

## 11. 미정 (추후 협의)
- 퀴즈에서 진화시킨 포켓몬의 출전 형태 (원본 스타터 선택은 1단계 포켓몬 기준)
- 성장 요소(사탕·개체값·특성·패시브)와 퀴즈 보상 연결 방식
