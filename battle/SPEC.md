# 포켓로그 포크 사양서 (포켓몬 배움 탐험대 연동)

- 원본: `pagefaultgames/pokerogue` (AGPL-3.0) → 본인 계정으로 포크
- 연동 앱: `i20091119-ai/2026poketquiz` (Cloudflare Workers + D1)
- 원칙: 전투 한 턴 흐름·데미지 공식·웨이브 구성·보상 구조는 원본 그대로. 아래 항목만 변경.

## 1. 출전 포켓몬
- 퀴즈 앱에서 획득한 포켓몬만 스타터로 해제
- 게임 시작 시 퀴즈 앱 `GET /api/my-pokemon` → 전국도감 번호 목록 수신 (포켓로그 `SpeciesId` = 전국도감 번호)
- 수정 위치: `src/system/game-data.ts` 기본 스타터 해제 부분(`defaultStarterSpecies` 반복문) → 수신 목록으로 교체
- 매 실행 시 목록 기준으로 재구성 (로컬 저장된 도감 데이터로 해제 범위가 늘지 않게)
- 시작 레벨: 원본 그대로 Lv.5 (`game-mode.ts` `getStartingLevel`)
- 스타터 포인트 한도: 15 (원본 클래식 10). 위치: `src/ui/utils/starter-select-ui-utils.ts` `getRunValueLimit`

## 2. 포획 금지
- 전투 중 볼 명령 제거: `src/ui/handlers/command-ui-handler.ts`
- 포획 처리 차단: `src/phases/attempt-capture-phase.ts`
- 상점 보상의 볼(몬스터볼·울트라볼·로그볼·마스터볼) → 같은 등급의 다른 상점 아이템 중 무작위로 대체
  - 위치: `src/modifier/init-modifier-pools.ts`

## 3. 돌발 이벤트 · 이로치 (2026-10-02 바뀜: 이로치는 퀴즈에서만 얻는다)
- ~~포켓몬을 주는 이벤트 4종 → 파티 포켓몬의 이로치 지급~~ → **포켓로그에서는 이로치를 얻을 수 없음** (부모님 결정 2026-10-02, `QUIZ_RULES.shinyFromQuizOnly`)
  - 4종(`uncommon-breed-encounter.ts`, `the-pokemon-salesman-encounter.ts`, `dancing-lessons-encounter.ts`, `absolute-avarice-encounter.ts`, 모두 `src/data/mystery-encounters/encounters/`)은 포켓몬 대신 **그 이벤트와 같은 등급의 아이템 보상**: 세일즈맨(ULTRA) 2개, 희귀종(COMMON)·댄스(GREAT)·욕심쟁이(GREAT) 1개 + 남은 보상 칸 채움. 한국어 문구는 `battle-extras/locales-ko/mystery-encounters/` 에서 "동료가 되고 싶어 한다"를 "선물을 남기고 떠났다"로 바꿈
  - 포켓로그에서 받은 이로치를 퀴즈 앱에 보내던 것(`POST /api/battle/shiny`, `reportQuizShiny`, `flushQuizShinies`)은 끔. 서버 주소는 옛 화면이 열려 있어도 오류가 안 나게 아무것도 안 하고 답만 함. 지금까지 기록된 이로치(`state.shiny`)는 그대로
- 이로치는 퀴즈 볼에서 확률로 나오고(몬스터볼 2%·슈퍼볼 4%·하이퍼볼 7%·마스터볼/럭셔리볼/희귀 볼 12%, 보호자 개발자 메뉴에서 바꿈), 이로치 볼은 확정. 이미 가진 포켓몬이 이로치로 나와도 이로치를 새로 얻음 (퀴즈 앱 규칙, `lib/game-config.ts` `SHINY_CHANCE_DEFAULT`)

## 12. 이로치 출전 (구현됨, 2026-10-02)
- **어떤 이로치를 쓰나**: 퀴즈 앱 이로치 도감(`GET /api/my-pokemon` 응답의 `shiny`, 진화한 모습 포함)에 있는 이로치만. 퀴즈에서 얻지 않은 이로치(원본의 이로치·레어색·에픽색)는 팀 선택 화면에서 이로치로 바꿀 수 없음. 원본의 "이로치 바꾸기" 버튼은 끔(`QUIZ_RULES.shinyFromQuizOnly`)
- **색**: 퀴즈 앱 이로치 도감 그림(PokeAPI 공식 이로치)과 같은 공식 이로치 색 = 포켓로그의 1단계 이로치 색(`variant` 0, 도감 비트 `SHINY | DEFAULT_VARIANT`). 레어·에픽 색(`VARIANT_2·3`)은 열지 않음
- **팀 선택 화면**: 같은 스타터를 퀴즈에서 기본 모습과 이로치로 둘 다 가졌으면 격자에 **두 칸으로 따로** 나옴(기본 색 칸 + 바로 뒤에 이로치 색 칸, 처음부터 그 모습). 이로치만 가졌으면 이로치 칸만. 구현: `starter-select-ui-handler.ts` 의 `expandShinyCells`(같은 번호를 두 번 넣음)·`markShinyCells`(두 번째 칸 = 이로치 칸)·`applyCellShinyPreference`(칸을 고르면 그 스타터의 이로치 설정을 켬/끔), `StarterContainer.shinyCell`
- **둘 다 출전**: 원본은 같은 종을 팀에 두 번 못 넣지만 기본과 이로치는 각각 넣을 수 있음(`isInParty(starterId, shiny)`가 종과 이로치 여부로 구분). 스타터 포인트는 각자 따로 계산(팀 칸마다 비용을 더함). 팀 칸 그림도 칸에 저장된 모습으로 그림(`popPartyStarter`)
- **진화형**: 퀴즈에서 진화시킨 포켓몬이 진화한 모습으로 출전하는 규칙을 이로치에도 똑같이 적용 — `quizStartingSpecies(starterId, shiny)`가 이로치는 이로치 도감 기준으로 가장 많이 진화한 모습을 고름. `select-starter-phase.ts` `initBattle` 에서 이로치 도감에 없는 이로치는 막음
- **도감 해제**: `game-data.ts` `quizStarterAttr` 가 매 실행마다 스타터의 해제 속성을 퀴즈 기준으로 다시 맞춤(기본 모습 = 기본 포켓몬을 가졌을 때, 이로치 = 이로치 도감에 있을 때). 예전 `SHINY_KEEP_BITS`(이벤트 이로치 보존)는 없앰
- 시험: 보호자 공간 시뮬레이션의 "가진 포켓몬마다 이로치도 +1", "볼 열 때 이로치 100%" 로 기본·이로치 동시 표시와 동시 출전을 확인할 수 있음

## 13. 메가 출전 (설계만 — 지금은 만들지 않음)
나중에 "메가 해금 미션"을 만들 때 아래 규칙으로 구현한다. 퀴즈 앱 쪽은 메가 도감(`lib/megas.ts` 96종, `state.megas`)이 이미 있고 해금 방법만 비어 있다.
- **누가 고를 수 있나**: 해금한 메가 + 퀴즈에서 **최종 진화까지 시킨 포켓몬**일 때만. 팀 선택 화면에서 "모습 바꾸기"(원본의 폼 바꾸기 자리)로 메가 모습을 고를 수 있음. 해금하지 않았거나 최종 진화 전이면 메가 모습은 목록에 나오지 않음
- **판 시작 때**: 메가 모습을 고르면 그 포켓몬이 **메가링과 자기 메가스톤을 자동으로 지닌 채** 시작(원본 메가진화 방식 그대로: 전투 중 메가진화 버튼으로 변신). 메가스톤 종류는 메가 모습(`MEGA`·`MEGA_X`·`MEGA_Y`·`MEGA_Z` 등 `SpeciesFormKey`)과 짝지은 원본의 폼 변화 아이템을 씀
- **한 판에 메가 1마리**: 팀에 메가 모습을 둘 이상 넣을 수 없음(팀 선택 화면에서 두 번째 메가를 고르면 막고 안내)
- **스타터 포인트**: 메가 모습을 골라도 그 포켓몬 그대로(추가 비용 없음)
- **열리는 순서**: 전설·환상 메가(뮤츠 X/Y, 레쿠쟈, 라티아스/라티오스, 지가르데, 디안시, 마기아나 등)는 **가장 마지막에** 열림
- **이로치와의 관계**: 이로치 포켓몬도 메가 모습을 고를 수 있게 하되(색은 그 포켓몬의 이로치 색), 퀴즈 앱 메가 해금은 종(도감 번호) 기준이라 기본·이로치 어느 쪽이든 해금 조건이 같음 — 구현할 때 다시 확인
- **구현 힌트**: `GET /api/my-pokemon` 응답에 `megas`(해금한 메가 키 목록, 퀴즈 앱 `lib/megas.ts` 의 `key`)를 더하고, 팀 선택 화면의 폼 바꾸기가 그 목록과 "최종 진화까지 시킨 포켓몬"(`quizStartingSpecies`가 가장 진화한 모습을 줄 때)을 모두 만족할 때만 메가 폼을 열어 줌. `initBattle`에서 메가 폼이면 메가링(`MegaBracelet` 같은 원본 아이템)과 메가스톤을 `globalScene.addModifier` 로 지급. 이 단계는 퀴즈 앱 쪽 해금 미션이 정해진 뒤에 한다


## 14. 배틀 힘 (퀴즈 열매·상처약 → 개체값, 2026-10-03)
- 퀴즈 앱에서 열매·상처약을 먹인 포켓몬 계열은 개체값 6개가 모두 +1 (시작 15, 최대 31). 기본 모습과 이로치는 같은 계열이면 같은 값.
- 퀴즈 서버 `GET /api/my-pokemon`의 `ivs`(퀴즈 번호 → 값)를 `quiz-link.ts`가 스타터 계열별 값(`quizStarterIv`)으로 바꾸고, `game-data.ts`가 실행마다 도감 개체값을 이 값으로 맞춤(새 기록 `initDexData`·기존 기록 `applyQuizStarterUnlocks`). 팀 선택 화면의 개체값 표시와 판 시작 포켓몬에 그대로 쓰임.
